# 📊 Recruiter-Ready Job Market Dashboard

## 📌 Project Overview
This project builds a **creative and interactive dashboard in Python (Plotly)** to analyze job postings data.  
It provides recruiters, career services, and job seekers with actionable insights into **industries, salaries, skills, competition, and hiring trends**.

---

## 🎯 Objectives
- Visualize **applications by industry** using treemaps.
- Track **job posting trends over time**.
- Analyze **salary distribution vs experience** with violin plots.
- Highlight **Tableau skill demand** using donut charts.
- Show **competition index** (applicants per posting) with heatmaps.
- Identify **top hiring companies** with bar charts.
- Provide **KPI cards** for quick recruiter snapshots.

---

## 🛠️ Tech Stack
- **Python** (Data analysis & visualization)
- **Pandas** (Data manipulation)
- **Plotly** (Interactive charts & dashboard layout)
- **Jupyter Notebook** (Development environment)

---

## 📊 Dashboard Features
- **Treemap** → Applications by Industry  
- **Line Chart** → Job Postings Trend  
- **Violin Plot** → Salary vs Experience  
- **Donut Chart** → Tableau Skill Demand  
- **Heatmap** → Applicant Competition Index  
- **Bar Chart** → Top Hiring Companies  
- **KPI Cards** → Total postings, Avg salary, Tableau demand, Applicants  

---

## 🔎 Insights
- **Industries hiring most** → Target partnerships with top‑hiring sectors.  
- **Experience trends** → Many mid‑senior roles; candidates should upskill.  
- **Salary insights** → Highlight competitive pay ranges in analytics.  
- **Tableau demand** → Nearly 1 in 10 postings require Tableau skills.  
- **Competition index** → Entry‑level roles attract more applicants, senior roles fewer but specialized.  
- **Top companies** → Identify organizations aggressively expanding their analytics teams.
